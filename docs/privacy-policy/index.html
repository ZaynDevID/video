Kebijakan Privasi

Berlaku sejak 3 November 2026 · Diperbarui 3 November 2026

Ringkasnya: Video adalah pemutar video lokal/offline. Aplikasi tidak memiliki akun, iklan, analytics, atau izin internet. File video dan data perpustakaanmu tetap di perangkatmu dan tidak dikirim ke mana pun.

1. Siapa yang mengelola aplikasi ini

Aplikasi Video (paket com.zayndev.video) dikembangkan dan diterbitkan oleh ZaynDev. Pertanyaan tentang privasi dapat disampaikan melalui tombol Email pengembang pada halaman resmi aplikasi di Google Play.

2. Data yang diakses

  • File video di perangkat. Dengan izinmu, aplikasi membaca file video dari penyimpanan perangkat agar dapat menampilkan dan memutarnya.
  • Pengaturan aplikasi. Tema, urutan tampilan, dan pilihan tampilan disimpan secara lokal.
  • Riwayat menonton. Posisi terakhir setiap video disimpan secara lokal agar fitur Lanjutkan menonton bekerja. Riwayat ini bisa dihapus dari menu Lainnya.
  • Subtitle yang dipilih. Jika kamu memilih file subtitle, aplikasi hanya membacanya dari lokasi yang kamu pilih dan menampilkannya selama pemutaran.
  • Log crash. Jika aplikasi mengalami error, ringkasan teknis (termasuk model perangkat dan versi Android) dapat ditulis ke folder aplikasi dan/atau Downloads/Video. Log ini tidak dikirim otomatis dan hanya ada di perangkatmu.

Aplikasi tidak mengakses kontak, lokasi, kamera, mikrofon, atau riwayat penjelajahan.

3. Izin yang digunakan

  • READ_MEDIA_VIDEO (Android 13+) dan READ_EXTERNAL_STORAGE (Android 12 ke bawah): membaca file video.
  • READ_MEDIA_VISUAL_USER_SELECTED (Android 14+): memungkinkan akses hanya ke video yang kamu pilih saat memakai opsi akses terbatas.

Izin hanya diminta saat diperlukan dan dapat dicabut kapan saja melalui pengaturan Android.

4. Pengumpulan dan pembagian data

Kami tidak mengumpulkan, menjual, menyewakan, atau membagikan data pribadi. Aplikasi tidak menggunakan SDK iklan, analytics, pelacakan, atau layanan pihak ketiga yang mengirim data. Tidak ada data yang dikirim ke server kami karena aplikasi tidak memiliki koneksi internet.

5. Penyimpanan dan penghapusan

Pengaturan dan riwayat menonton disimpan di perangkat sampai kamu menghapus data aplikasi atau menghapus instalasinya. File subtitle hanya dibaca selama sesi pemutaran; aplikasi tidak menyalin isinya. File video asli tidak diubah atau dihapus oleh aplikasi. Log crash di Downloads/Video dapat kamu hapus sendiri melalui pengelola file.

6. Keamanan

Karena data tidak dikirim keluar perangkat, risikonya terutama bergantung pada keamanan perangkatmu. Kami menyarankan menjaga kunci layar dan mencadangkan file video penting secara terpisah.

7. Anak-anak

Aplikasi ini bukan layanan yang ditujukan khusus untuk anak di bawah 13 tahun dan tidak dengan sengaja mengumpulkan data pribadi anak. Aplikasi hanya memutar file video yang sudah ada di perangkat atau yang dipilih pengguna.

8. Tautan ke situs lain

Menu Kebijakan Privasi di aplikasi membuka halaman ini melalui browser. Jika kamu membuka tautan lain, kebijakan privasi situs tersebut berlaku. Aplikasi tidak mengirim data ke browser.

9. Perubahan kebijakan

Jika praktik data berubah, halaman ini akan diperbarui dan tanggal di bagian atas akan diubah. Versi terbaru selalu tersedia di alamat ini.

10. Kontak

Untuk pertanyaan, koreksi, atau permintaan terkait privasi, gunakan tombol Email pengembang pada halaman Google Play aplikasi Video. Kami akan menanggapi melalui saluran yang tersedia di listing tersebut.
